**Chip** — mono, uppercase, pill tag. The default way to label a technology, status, or category.

```jsx
<Chip>Azure</Chip>
<Chip color="var(--color-primary)" borderColor="rgba(0,120,212,0.3)">Zero Trust</Chip>
```

Cyan by default. Pass `color` / `borderColor` to recolor (e.g. primary-blue on portfolio case-study labels). For square-bracketed `[TAG]` styling, use `BracketTag` instead.
