**BracketTag** — a `[ TAG ]` mono token with literal square brackets that brighten on hover. Use for hero specialization tokens and portfolio tech stacks where `Chip` would feel too soft.

```jsx
<BracketTag>Azure Architect</BracketTag>
<BracketTag>Rust &amp; WASM</BracketTag>
```

Dimmed cyan at rest; border, text, and brackets all intensify on hover. Pair several in a flex row with `gap`.
