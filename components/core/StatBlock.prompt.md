**StatBlock** — a proof metric: a big gradient-text number with a small mono caption underneath. Pair with a case-study card.

```jsx
<StatBlock stat="40%" label="Cost reduction" />
<StatBlock stat="1,200" label="Users secured" align="left" />
```

Keep the figure punchy (a percentage, a count, "14yr", "∞"). The gradient + Space Grotesk weight does the work — don't add a glow on top.
